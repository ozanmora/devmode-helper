# Installation

Make sure you have the latest version of the Xcode command line tools installed:

```sh
xcode-select --install
```

For _fastlane_ installation instructions, see [Installing _fastlane_](https://docs.fastlane.tools/#installing-fastlane)

# Available Actions

## Android

### android build

```sh
[bundle exec] fastlane android build
```

Uygulamayı derler ve build/devmode-helper.apk dosyasını üretir

### android prerelease

```sh
[bundle exec] fastlane android prerelease
```

APK derler, sürüm ve build number ile git tag koyar, GitHub'da pre-release olarak yayınlar
